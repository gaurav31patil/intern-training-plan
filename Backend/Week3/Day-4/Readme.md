## **Day 4 — PostgreSQL with Node.js (pg Library)**

### **Learn**

- Connecting Node.js to PostgreSQL using the **pg** library
- Querying from Express routes
- Using `async/await` for DB calls
- Preventing SQL injection with **parameterized queries**
- Error handling patterns

### **References**

- node-postgres (pg) — [https://node-postgres.com/](https://node-postgres.com/)
- SQL Prepared Statements — [https://www.w3schools.com/sql/sql_injection.asp](https://www.w3schools.com/sql/sql_injection.asp)

### **What to Build**

- Create `db.js` that establishes a PostgreSQL connection
- Build Express CRUD endpoints for a resource (books, orders, tasks, etc.)
- Use parameterized queries to protect against SQL injection
- Add validation and proper HTTP status responses
