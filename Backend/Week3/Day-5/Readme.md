- When to choose MongoDB vs PostgreSQL
- Schema design best practices
- Data relationships (`1:1`, `1:M`, `M:N`)
- Indexing basics for performance

## **Mini Project Options**

Choose one (or propose your own) and build it using **both MongoDB & PostgreSQL**:

- Task Manager (tasks + users)
- Notes App
- Inventory System
- Student Management System

### **Requirements**

- Implement CRUD in MongoDB
- Implement CRUD in PostgreSQL
- Compare schema design for each version
- Add at least one search/filter feature
- Add basic validation
