## **Day 2 — MongoDB with Mongoose (Node.js Integration)**

### **Learn**

- What Mongoose is and why it’s used
- Defining **schemas** and **models**
- Connecting MongoDB to an Express server
- Mongoose methods: `find`, `findById`, `create`, `updateOne`, `deleteOne`
- Schema validation basics

### **References**

- Mongoose Guide — [https://mongoosejs.com/docs/guide.html](https://mongoosejs.com/docs/guide.html)
- MongoDB CRUD — [https://www.w3schools.com/mongodb/mongodb_crud.asp](https://www.w3schools.com/mongodb/mongodb_crud.asp)

### **What to Build**

- Connect an Express server to MongoDB using Mongoose
- Create **User** and **Product** models with validation rules
- Build CRUD endpoints:

  - `POST /users`
  - `GET /users`
  - `PUT /users/:id`
  - `DELETE /users/:id`

- Test using Postman / Thunder Client and verify validations
