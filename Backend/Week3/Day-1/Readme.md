## **Day 1 — Introduction to Databases & MongoDB Basics**

### **Learn**

- Difference between SQL and NoSQL
- What MongoDB is and where it’s used
- Documents, collections, and schema-less design
- Installing MongoDB or using MongoDB Atlas
- Basic CRUD operations in MongoDB shell

### **References**

- MongoDB Basics (W3Schools) — [https://www.w3schools.com/mongodb/](https://www.w3schools.com/mongodb/)
- What is a Database — [https://www.w3schools.com/whatis/whatis_db.asp](https://www.w3schools.com/whatis/whatis_db.asp)

### **What to Build**

- Create a **users collection** in MongoDB (local or Atlas) and insert multiple documents (`name`, `age`, `email`, `role`)
- Query users using filters (age range, name, role)
- Update documents using `updateOne()` and `updateMany()`
- Delete documents using `deleteOne()` and `deleteMany()`
