## **Day 3 — PostgreSQL (SQL) Fundamentals**

### **Learn**

- What PostgreSQL is and when SQL is preferred
- Tables, rows, columns, and data types
- Primary keys, foreign keys, and relationships
- SQL CRUD (`SELECT`, `INSERT`, `UPDATE`, `DELETE`)
- Sorting, filtering, `LIMIT`, `JOIN`

### **References**

- SQL Tutorial — [https://www.w3schools.com/sql/](https://www.w3schools.com/sql/)
- PostgreSQL Intro — [https://www.w3schools.com/postgresql/](https://www.w3schools.com/postgresql/)

### **What to Build**

- Create a PostgreSQL database and a table (e.g., users or tasks)
- Insert sample rows manually
- Write SQL queries: `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- Write queries with `WHERE`, `ORDER BY`, `LIMIT`
- Create a second table and run a basic **JOIN**
