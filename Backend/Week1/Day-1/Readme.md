## **Day 1 — JavaScript Basics**

### **Learn**

- `let` vs `const`
- Primitive types
- Operators
- Template strings
- Basic arrays and objects

### **References**

- JS Introduction — [https://www.w3schools.com/js/js_intro.asp](https://www.w3schools.com/js/js_intro.asp)
- Variables — [https://www.w3schools.com/js/js_variables.asp](https://www.w3schools.com/js/js_variables.asp)

### **What to Build**

- Create a simple arithmetic calculator that performs **addition, subtraction, multiplication, and division**, and print results using `console.log()`.
- Create a **User object** with properties (`name`, `age`, `email`, `score`, `level`, `active`, `achievements`) and print a formatted summary using **template strings**.
- Update values in the User object (`score`, `level`, `active`, `achievements`) using operators and print results **before and after changes**.
