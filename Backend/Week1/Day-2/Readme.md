## **Day 2 — Arrays, Objects & Core Methods**

### **Learn**

- Common array methods: `map`, `filter`, `reduce`, `find`, `sort`, `some`, `every`
- Useful object utilities: `Object.keys`, `Object.values`, `Object.entries`
- Array/Object destructuring
- Spread operator

### **What to Build**

- Work with a list of products:

  - filter expensive items
  - map product names
  - calculate total & average values using `reduce`
  - print formatted results

- Sort a list of students by marks and print the highest and lowest scorer
- Convert a product object into an array using `Object.entries()` and rebuild it using `Object.fromEntries()`
- Use destructuring and spread operator to clone an object & modify selected fields
