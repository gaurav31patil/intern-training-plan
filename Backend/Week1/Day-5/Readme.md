## **Day 5 — TypeScript Fundamentals**

### **Learn**

- Basic types (`string`, `number`, `boolean`)
- Interfaces and type aliases
- Enums and union types
- How TypeScript compiles to JavaScript
- Basic `tsconfig` setup

### **References**

- TypeScript Docs — [https://www.typescriptlang.org/docs/](https://www.typescriptlang.org/docs/)

### **What to Build**

- Convert earlier JS practice files (User, Product, Students) into TypeScript using type annotations
- Create **interfaces** for User, Product, and Student — use them to strongly type objects & arrays
- Create an **enum** for user roles and validate values via a function
- Build a small TS script that processes typed arrays & returns filtered results
