# **📍 1-Month Backend Intern Learning Plan**

This structured one-month plan guides a backend intern from fundamental programming skills to building and deploying a complete backend application.
The pace is beginner-friendly and emphasizes **hands-on learning**.

### **Daily Routine**

Each day follows the structure:

- **Learning** — Core concepts, examples, theory
- **Building** — A practical exercise to apply the concepts immediately

---

## **🎯 End-of-Month Outcomes**

By the end of the internship, the intern will:

- Understand and confidently write **JavaScript & TypeScript**
- Build server applications using **Node.js & Express.js**
- Work with databases: **MongoDB & PostgreSQL**
- Implement **authentication (JWT)** and secure REST APIs
- Deploy a **production-ready backend project**
- Follow real-world backend development structure and practices

---

## **📅 Weekly Themes Overview**

### **Week 1 — JavaScript + TypeScript Fundamentals**

Build a strong foundation with modern JavaScript and TypeScript.
Learn ES6+ syntax, functional utilities, objects, arrays, and async programming to ensure readiness for backend development.

---

### **Week 2 — Node.js + Express.js + Basic Database Integration**

Understand how backend servers work:

- Routing
- Middleware
- Controllers
- HTTP lifecycle
- Integrating simple CRUD API endpoints
- Connecting to MongoDB or PostgreSQL

By the end of the week, the intern will build functional APIs.

---

### **Week 3 — Databases: MongoDB + PostgreSQL**

Deep dive into:

- Schema design
- Relationships
- CRUD operations
- Indexing & query optimization
- SQL vs NoSQL choice
- Using **Mongoose** and **pg**

---

### **Week 4 — Final Backend Project (Full CRUD + Auth)**

Build a complete real-world backend system:

- JWT authentication
- Validation
- Pagination & filtering
- Error handling
- Logging and security
- DTO structure & documentation

---

## **📌 Topics Covered Throughout the Month**

### **JavaScript & TypeScript**

- ES6+ features (modules, arrow functions, destructuring, spread/rest)
- Array & object utilities (`map`, `filter`, `reduce`, `find`, `sort`)
- Async programming (`promises`, `async/await`, event loop)
- TypeScript: types, interfaces, enums, unions, narrowing, generics

### **Backend Development**

- Node.js runtime & architecture
- Express.js routing, middleware, controllers
- REST API design principles & best practices
- Folder structure and clean code patterns

### **Databases**

- MongoDB + Mongoose (documents, schemas, models)
- PostgreSQL (SQL queries, joins, relationships, constraints)
- Choosing SQL vs NoSQL
- Indexing, pagination, filtering optimizations

### **Project & Professional Skills**

- JWT authentication & authorization
- CRUD endpoints with validation (Yup / express-validator)
- Environment configuration (dotenv)
- Pagination & search queries
- Logging, CORS, rate-limiting security basics

---

## 🚀 Final Goal

A **fully functional production-level backend application** featuring:

| Feature        | Description                                |
| -------------- | ------------------------------------------ |
| Authentication | JWT + roles                                |
| CRUD           | Create, read, update, delete API endpoints |
| Validation     | Input validation and error handling        |
| Database       | MongoDB or PostgreSQL with relationships   |
| Features       | Search, filtering, pagination              |
| Documentation  | README or Postman collection export        |
