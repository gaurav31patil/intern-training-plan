## **Day 1 — Introduction to Node.js**

### **Learn**

- What Node.js is and why it’s used
- The Node.js runtime and event-driven architecture
- Working with built-in modules (`fs`, `path`)
- Using npm and understanding `package.json`
- Running scripts, ES modules, and basic project setup

### **References**

- Node.js Intro — [https://www.w3schools.com/nodejs/nodejs_intro.asp](https://www.w3schools.com/nodejs/nodejs_intro.asp)
- Node.js Modules — [https://www.w3schools.com/nodejs/nodejs_modules.asp](https://www.w3schools.com/nodejs/nodejs_modules.asp)

### **What to Build**

- Create a script that **reads and writes text to a file** using the Node.js `fs` module
- Build a simple **notes manager** using filesystem storage with commands to create, read, and list notes
- Install a third-party package using npm (example: `lodash`) and test it inside your script
