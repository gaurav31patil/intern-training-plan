## **Day 4 — Introduction to Databases in Express**

### **Learn**

- Why servers need databases
- SQL vs NoSQL differences
- How to handle async database operations
- Using environment variables (`dotenv`)
- Basic database integration flow

### **References**

- dotenv — [https://www.npmjs.com/package/dotenv](https://www.npmjs.com/package/dotenv)
- SQL vs NoSQL — [https://www.w3schools.com/whatis/whatis_db.asp](https://www.w3schools.com/whatis/whatis_db.asp)

### **What to Build**

- Create a `config/` folder and load environment variables using dotenv (e.g., `PORT`, `MODE`)
- Create fake database utility functions returning **Promises** (simulate async DB operations)
- Build CRUD API endpoints using **in-memory storage** (array or object)
- Add request validation for create/update and return proper status codes
