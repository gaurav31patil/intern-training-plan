## **Day 3 — Middleware, Controllers & API Structure**

### **Learn**

- What middleware is and how it works
- Built-in middleware (`express.json`, `express.urlencoded`)
- Custom middleware (logging, validation)
- Controller-based project structure
- Error-handling middleware

### **References**

- Express Middleware — [https://www.w3schools.com/nodejs/nodejs_express.asp](https://www.w3schools.com/nodejs/nodejs_express.asp) _(see middleware section)_

### **What to Build**

- Add custom **logging middleware** printing method, route, timestamp
- Add **validation middleware** that checks request body values
- Move route logic into separate **controller files**
- Implement a **global error-handling middleware** returning standardized responses
