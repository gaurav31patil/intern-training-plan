## **Day 2 — Express.js Basics**

### **Learn**

- What Express is and why it’s the most common Node backend framework
- Creating a basic Express server
- Handling routes (`GET`, `POST`, `PUT`, `DELETE`)
- Working with request & response objects
- Structuring routes in separate files

### **References**

- Express.js Intro — [https://www.w3schools.com/nodejs/nodejs_express.asp](https://www.w3schools.com/nodejs/nodejs_express.asp)

### **What to Build**

- Create a basic Express server that listens on a port and returns a JSON response for `/`
- Add multiple API routes (`/`, `/about`, `/users`) returning text or JSON
- Create a `routes/` folder and move each route into its own file, then import them into the main server
- Build a simple API returning an in-memory **list of users/products** using `GET`, `POST`, `PUT`, `DELETE`
