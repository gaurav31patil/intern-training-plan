# Intern Training Plan

This repository contains a structured **2‑month learning roadmap** designed for interns to progressively build strong foundational skills in **Frontend and Backend development**, ending with fully functional real‑world projects.

The program is divided into two major phases: **Backend (Month 1)** and **Frontend (Month 2)**, each consisting of weekly and daily structured learning.

---

## 📂 Repository Index

### **Backend Month (Month 1)**

| Week   | Description                                 | Path                           |
| ------ | ------------------------------------------- | ------------------------------ |
| Week 1 | JavaScript + TypeScript Fundamentals        | [Backend/Week1](Backend/Week1) |
| Week 2 | Node.js + Express.js + Basic DB Integration | [Backend/Week2](Backend/Week2) |
| Week 3 | MongoDB + PostgreSQL & Schema Design        | [Backend/Week3](Backend/Week3) |
| Week 4 | Final Backend CRUD + Auth Project           | [Backend/Week4](Backend/Week4) |

#### **Daily Structure**

Each Week folder contains **Day 1 → Day 5** subfolders, each including:

* Learning Plan
* Practice exercise
* Questions & notes
