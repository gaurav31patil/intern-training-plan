# **📍 1-Month Frontend Intern Learning Plan**

This structured 1-month training program focuses on developing practical frontend engineering skills through progressive learning, guided exercises, and real project implementation.

Since **JavaScript and TypeScript fundamentals were already covered in the backend training month**, this program begins directly with **HTML, CSS, UI frameworks, React.js, and Next.js**.

The structure is **beginner-friendly**, designed to strengthen foundational UI development and gradually build toward real-world application building.

---

### **Daily Learning Structure**

Each day includes:

- **Learning** — Concepts, examples, and best practices
- **Building** — Practical tasks to apply concepts immediately

---

## **🎯 End-of-Program Outcomes**

By the end of the program, the intern will be able to:

✔ Build **responsive web layouts** using HTML, CSS, Bootstrap, and Tailwind
✔ Develop **interactive UI components** in React.js
✔ Build **production-style Next.js applications** with routing and data fetching
✔ Integrate APIs, manage state, and implement role-based functionality
✔ Deliver a polished **Task Management System frontend** as the final project

---

## **📅 Training Progression (Weekly Themes)**

### **Week 1 — HTML, CSS & Responsive Design**

Semantic structure, layout systems, Flexbox, CSS Grid, responsive utilities, and modern styling fundamentals.

### **Week 2 — React.js Fundamentals**

Component-based architecture, props, state, hooks, reusable UI components, event handling, and REST API integration.

### **Week 3 — Advanced React + Next.js Essentials**

Context API, useReducer, optimization patterns, routing fundamentals, SSR/SSG, Next.js data fetching, and shared layouts.

### **Week 4 — Final Project: Task Manager UI**

Authentication screens, task CRUD interface, global state, search/filtering, role-based UI, and responsive professional styling.
