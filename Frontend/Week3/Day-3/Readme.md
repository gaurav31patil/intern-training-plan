## **Day 3 — Introduction to Next.js**

### **Learn**

- What Next.js is & why it’s used
- File-based routing
- Pages vs components
- Layouts & shared components
- Navigation using `next/link`

### **Resources**

- Next.js Intro — [https://nextjs.org/docs](https://nextjs.org/docs)
- Routing — [https://nextjs.org/docs/app/building-your-application/routing](https://nextjs.org/docs/app/building-your-application/routing)

### **What to Build**

- Create a new Next.js project & run locally
- Build pages using file-based routing:

  - `pages/index.tsx`
  - `pages/about.tsx`
  - `pages/contact.tsx`

- Create a global layout with nav + footer wrapping all pages
- Use `next/link` for client-side navigation
- Add styling using **CSS modules** or **Tailwind**
