## **Day 4 — Data Fetching in Next.js: SSR, SSG & API Routes**

### **Learn**

- `getStaticProps`, `getServerSideProps`, `getStaticPaths`
- When to use **SSR vs SSG**
- Client-side vs server-side data fetching
- Creating API routes inside Next.js

### **Resources**

- Data Fetching — [https://nextjs.org/docs/pages/building-your-application/data-fetching](https://nextjs.org/docs/pages/building-your-application/data-fetching)
- API Routes — [https://nextjs.org/docs/pages/building-your-application/routing/api-routes](https://nextjs.org/docs/pages/building-your-application/routing/api-routes)

### **What to Build**

- Create a dynamic route page: `/users/[id].tsx`
- Use **getServerSideProps** to fetch data dynamically
- Create a static page using **getStaticProps** for pre-rendered content
- Build a Next.js API route in `/pages/api/*`
- Fetch from the API route in a page and display loading behavior
