## **Day 1 — Context API & Advanced State Management**

### **Learn**

- Prop drilling problem & global state patterns
- Context API: `createContext`, `Provider`, `useContext`
- When to use **Context vs useState vs useReducer**
- `useReducer` for structured state updates

### **Resources**

- Context API — [https://react.dev/learn/passing-data-deeply-with-context](https://react.dev/learn/passing-data-deeply-with-context)
- useReducer — [https://react.dev/reference/react/useReducer](https://react.dev/reference/react/useReducer)

### **What to Build**

- Convert Todo or User Directory App to use Context API instead of props drilling
- Create `ThemeContext` or `AuthContext` for theme or login state
- Implement `useReducer` to manage Todo/User app actions (add, delete, update)
- Provide and consume global context across multiple components
