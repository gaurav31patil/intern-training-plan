## **Day 5 — Mini Project & Review**

### 🧠 **Mini Project Goal**

Build a **User Profiles App** using **Next.js** with server-side or static data fetching, global state, and responsive UI.

---

### **Mini Project Requirements**

**Build a User Profiles App with:**

- **Home page** displaying list of users (using **SSR** or **SSG**)
- **Dynamic user details page** using `/users/[id].tsx`
- **Context API** for theme or authentication state
- **Tailwind CSS or Bootstrap** for styling and layout

---

### **Optional Enhancements**

- Search bar for filtering users
- Pagination or infinite scroll
- Loading & error UI
- Reusable UI components (Card, Spinner, Button, etc.)

---

### **What to Build (Checklist)**

- [ ] Create a new Next.js project
- [ ] Build a Home page displaying a list of users using API + getServerSideProps / getStaticProps
- [ ] Create `/users/[id].tsx` page to show selected user details
- [ ] Add global state via Context (theme toggle or login state)
- [ ] Style with Tailwind or Bootstrap
- [ ] Add search functionality for filtering displayed users
- [ ] Add loading / empty state UI components
