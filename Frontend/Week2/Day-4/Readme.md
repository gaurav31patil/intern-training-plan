## **Day 4 — useEffect, API Calls & Component Lifecycle**

### **Learn**

- `useEffect` and lifecycle events
- Fetching data from an API (`fetch` or `axios`)
- Loading and error states
- Side effects & dependency arrays

### **Resources**

- useEffect — [https://react.dev/reference/react/useEffect](https://react.dev/reference/react/useEffect)
- Fetch API — [https://www.w3schools.com/js/js_api_fetch.asp](https://www.w3schools.com/js/js_api_fetch.asp)

### **What to Build**

- Component that **fetches data** from a public API (users, Pokémon, posts, etc.)
- Trigger fetch on load using `useEffect`
- Display **loading** and **error** states
- Add **search or filtering**
- Display results as styled cards or list
