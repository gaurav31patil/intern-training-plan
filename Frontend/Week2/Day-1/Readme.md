- What React is and why it’s used
- SPA vs MPA architecture

### **What to Build**

- Initialize a new React project using **Create React App** or **Vite**
- Create basic components: `Header`, `Main`, `Footer`, and render them in `App.jsx`
- Display a list of items using `.map()` (skills, features, products, etc.)
- Style layout using CSS or Tailwind/Bootstrap CDN
