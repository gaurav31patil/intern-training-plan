## **Day 5 — Mini Project & Review**

### **Mini Project**

Build a **User Directory App** including:

- API-based list of users
- Search bar & live filtering
- Details card or modal popup

- What React concepts do you feel confident about now?

- What reusable patterns do you want to improve?
