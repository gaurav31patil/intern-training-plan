## **Day 3 — Tasks UI: CRUD, Modals & Reusable Components**

### **Learn**

- Reusable components patterns
- Controlled forms in React
- Modal dialogs for editing & creating records
- Loading and empty UI patterns

### **What to Build**

- Create **Tasks page UI** showing list or table of tasks
- Build **Create/Edit Task modal** using controlled form fields
- Add CRUD operations: add, edit, delete tasks
- Create reusable components:

  - `Button`
  - `Input`
  - `Modal`
  - `TaskCard`

- Show loading, empty, and error states conditionally
