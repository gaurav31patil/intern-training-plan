## **Day 2 — Authentication & Protected Routing**

### **Learn**

- Login form handling & validation
- Protected routes using Next.js middleware
- Role-based UI logic (Admin / Manager / Developer)

### **What to Build**

- Create **Login page UI** with controlled input fields
- Store user details (**JWT + role**) in `AuthContext`
- Implement protected routes using **Next.js Middleware**
- Redirect unauthenticated users to `/login`
- Conditionally show/hide UI elements based on role
