## **Day 5 — Frontend Testing, Accessibility & UI/UX Best Practices**

### **Learn**

- Accessibility basics (ARIA, roles, keyboard support)
- UI testing with **React Testing Library**
- Performance testing in browser DevTools
- UX principles: spacing, alignment, contrast, feedback

### **What to Build**

- Add accessibility improvements across UI components (labels, aria attributes)
- Implement baseline UI tests using React Testing Library (optional but recommended)
- Add toast notifications for success/error actions
- Test full task workflow manually:

  ```
  create → edit → delete → update status
  ```

- Polish UI: spacing, alignment, hierarchy, loading indicators
