## **Day 3 — Layouts: Flexbox & CSS Grid**

### **Learn**

- Flexbox: axis, alignment, gap, wrap behavior
- Grid: rows, columns, `repeat()`, `fr` units
- Mobile-first responsive design
- Media queries

### **What to Build**

- Convert your layout from Day 1 to **Responsive Flexbox**
- Use Flexbox to align elements horizontally in navbar & hero section
- Create **3-column feature cards** using CSS Grid
- Make columns **stack on mobile screens**
