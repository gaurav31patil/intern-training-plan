## **Day 2 — CSS Fundamentals**

### **Learn**

- CSS syntax, selectors, classes, IDs
- Colors, fonts, text styling, spacing (margin & padding)
- Box model (border, padding, width, height)
- Display: `block`, `inline`, `inline-block`, `none`

### **Resources**

- CSS Basics — [https://www.w3schools.com/css/css_intro.asp](https://www.w3schools.com/css/css_intro.asp)
- Box Model — [https://www.w3schools.com/css/css_boxmodel.asp](https://www.w3schools.com/css/css_boxmodel.asp)

### **What to Build**

- Style the landing page with an external `style.css`
- Apply typography (font family, size, weight, line height)
- Style navbar and hero background (color or image)
- Add spacing using margin & padding
- Style contact form inputs & buttons
