## **Day 1 — HTML & Web Structure**

### **Learn**

- What HTML is and how browsers render a webpage
- Document structure: `<html>`, `<head>`, `<body>`
- Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Forms & inputs, tables, media elements (`img`, `video`)

### **Resources**

- HTML Basics — [https://www.w3schools.com/html/html_intro.asp](https://www.w3schools.com/html/html_intro.asp)
- Semantic Elements — [https://www.w3schools.com/html/html5_semantic_elements.asp](https://www.w3schools.com/html/html5_semantic_elements.asp)

### **What to Build**

- Create a **basic landing page** following semantic structure
- Add a **hero section** (title, subtitle, call-to-action button)
- Add an **about section** with text + an image placeholder
- Add a **contact form** (name, email, message, submit button)
- Create a **simple navigation menu** linking to page sections
